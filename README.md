# Hospital Emergency Room Analytics — EDA Project

## About the Project

This project focuses on exploring hospital emergency room data using Python.

I worked with a dataset containing 9,216 patient visit records to understand patient demographics, admission patterns, department referrals, waiting times, and patient satisfaction.

The main goal was to explore the data, identify patterns, and understand how data analysis can help in studying hospital operations.

## Objectives

- Analyze patient demographics and visit patterns.
- Understand patient admission rates.
- Identify the most frequently referred departments.
- Explore emergency room waiting times.
- Analyze patient satisfaction scores.
- Visualize important patterns in the dataset.

## Dataset

The dataset contains 9,216 patient visit records and 12 columns.

Some of the important attributes are:

- Patient age, gender, and race
- Admission date
- Department referral
- Patient admission status
- Waiting time
- Patient satisfaction score

**Note:** Some columns contain missing values. Patient satisfaction scores are missing for many records, so the results from this analysis should be interpreted carefully.

## Project Workflow

1. Loaded the dataset into Python.
2. Checked the dataset structure and data types.
3. Identified missing values and duplicate records.
4. Cleaned and prepared the data.
5. Performed exploratory data analysis.
6. Created charts to visualize the results.
7. Analyzed the patterns and summarized the findings.

## Analysis Performed

The following areas were explored:

- Gender and age distribution
- Patient admission status
- Department referral patterns
- Emergency room waiting times
- Patient satisfaction scores
- Admission rates across age groups
- Monthly patient visit trends
- Key performance indicators (KPIs)

## Key Findings

The analysis helped explore different patterns in emergency room visits.

Some of the important findings include:

- Average Patient Age: 39.86
- Overall admission rate: 50.04%
- Most frequently referred department: No Referral
- Average waiting time: 35.26 minutes

These findings are based on the dataset and the visualizations created during the analysis.
